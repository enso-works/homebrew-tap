# enso-works/homebrew-tap

```sh
brew install --cask enso-works/tap/devdash
brew install --cask enso-works/tap/game-audio-asset-manager
```

| Cask | Description |
|------|-------------|
| [devdash](https://github.com/enso-works/devdash) | Menu bar dashboard for dev servers, Docker containers and Claude Code |
| [game-audio-asset-manager](https://github.com/enso-works/game-audio-asset-manager) | Download, edit, loop and export game audio for Godot and three.js |

Each cask is updated by its project's release workflow.
